# canon

A three-voice canon, MML/MIDI score renderer, and audio-reactive bar
visualizer implemented in standard Lv9 SysY.

The sample score in `canon.mml` follows Pachelbel's ground bass at 70 BPM. One
96-tick melody enters three times, 32 ticks apart, forming an imitative canon
across the left, center, and right stereo positions.

## Pure SysY audio rendering

`score2wav.c` reads either textual MML or a Standard MIDI File from standard
input and writes a 12 kHz, 16-bit stereo PCM WAV stream to standard output. It
auto-detects MIDI by its `MThd` signature.

WAV synthesis does **not** use FFmpeg, a sound font, floating point, or a host
audio library. Note parsing, tempo conversion, event scheduling, oscillators,
envelopes, stereo panning, and delay are all implemented in pure SysY.

The supported MML subset includes tempo, octave, default/explicit lengths,
velocity, pan, MIDI program, rests, accidentals, dotted notes, octave shifts,
and `;`-separated voices. The MIDI parser supports Format 0/1 with PPQ timing,
running status, Note On/Off, tempo events, Program Change, and pan controls.

Render any MML or MIDI score directly to WAV:

```sh
SYSY_COMPILER=/absolute/path/to/compiler \
  ./render.sh score.mml build/score.wav

SYSY_COMPILER=/absolute/path/to/compiler \
  ./render.sh score.mid build/score.wav
```

The equivalent Make target is:

```sh
make render \
  COMPILER=/absolute/path/to/compiler \
  SCORE=score.mid \
  OUTPUT=build/score.wav
```

## Video demo

`visualizer.c` emits the original 160x90, 15 FPS, YUV444 Y4M bar animation.
The complete demo build uses FFmpeg only in the final step to encode and mux
that Y4M stream with the WAV generated by `score2wav.c`.

```sh
SYSY_COMPILER=/absolute/path/to/compiler ./build.sh
```

or:

```sh
make COMPILER=/absolute/path/to/compiler
```

The pipeline is:

```text
canon.mml -> pure SysY score2wav -> canon.wav ----+
                                                  +-> FFmpeg -> canon-demo.mp4
pure SysY visualizer -> visualizer.y4m -----------+
```

FFmpeg is not involved in WAV generation.

## Files

* `canon.mml`: editable source score.
* `score2wav.c`: pure SysY MML/MIDI parser and WAV synthesizer.
* `visualizer.c`: pure SysY Y4M bar visualizer.
* `render.sh`: render any MML or MIDI input directly to WAV.
* `build.sh`: build the complete audiovisual demo.
* `clean.sh`: remove generated artifacts.

All generated assembly, objects, executables, WAV, Y4M, and MP4 files live in
the ignored `build/` directory and can be reproduced from source.
